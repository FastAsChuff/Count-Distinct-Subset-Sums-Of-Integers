# Count-Distinct-Subset-Sums-Of-Integers
This program calculates the number of unique subset sums achievable from a list of up to 1000 non-zero integers a_i in [-1000000000, 1000000000].

RAM Requirement approx. -> 16*answer bytes.

Usage:- ./numuniquesums.bin maxMB a_1 ... a_n


e.g.

./numuniquesums.bin 10 2 3 5 7 11

There are 23 unique sums of these 5 integers.
